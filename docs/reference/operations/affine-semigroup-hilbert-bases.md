# Two-dimensional affine-semigroup Hilbert bases

`affine_semigroup.hilbert_basis.compute` returns the complete Hilbert basis of
the rational cone generated by a labelled configuration in the ambient
lattice `Z^2`. The input must span a full-dimensional pointed cone. Each
returned vector is an ambient lattice point; the result retains the
configuration and its labelled row axis.

This is the Hilbert basis of the cone, equivalently the minimal additive
generators of `cone(A) ∩ Z^2`. It is not necessarily a generating set for the
possibly smaller semigroup generated by the supplied columns. The operation
does not make a Graver-basis, Markov-basis, or toric-ideal claim.

## Completeness and admission

The kernel finds the two primitive extreme rays `u,v`, oriented so
`D = det(u,v) > 0`. Every lattice point in the cone has unique rational
coordinates `αu + βv` with `α,β ≥ 0`. Subtracting `floor(α)u` and
`floor(β)v` leaves a lattice point in the semi-open fundamental parallelogram
`0 ≤ α,β < 1`. Thus any indecomposable point other than the two primitive
boundary rays must be among the nonzero lattice points in this parallelogram.
There are exactly `D` residue classes, obtained from a two-dimensional
Hermite-normal-form lattice basis. The operation tests this finite candidate
set for decomposability in increasing `α+β` order, using previously
established indecomposable points. This gives both a finite coverage argument
and an exact decomposability test.

The primitive-ray determinant is limited to 1,000, and the corresponding
quadratic pair-check estimate is admitted before enumeration. The result has
at most `D+1` vectors. Requests outside these limits receive a
resource-admission error; they are not partial Hilbert bases.

For generators `(1,0)` and `(1,3)`, the exact Hilbert basis is
`(1,0),(1,1),(1,2),(1,3)`.
