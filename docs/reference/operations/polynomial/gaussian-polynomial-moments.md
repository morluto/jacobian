# Exact bounded Gaussian polynomial moments

[Documentation home](../../../index.md) · [Tool surface](../../tools.md)

`probability.gaussian_polynomial.moment.compute` computes one stated exact
moment of a bounded sparse complex-rational polynomial in independent standard
real Gaussian variables. The result includes the finite coefficient
contraction ledger for that requested order.

The operation proves no identity for unrequested orders or different
parameters. Its polynomial, order, and result are all direct typed values;
there is no retained source polynomial or replay record.
