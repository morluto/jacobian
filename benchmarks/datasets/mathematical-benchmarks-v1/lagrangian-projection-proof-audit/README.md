# Lagrangian projection proof audit

This Hard research-proof task is derived from ArxivMathGradingBench row 11 and the author-corrected CC-licensed sources of arXiv:2502.00898. Version 1 silently used `D^T J D = 0` for an arbitrary nearby map; version 2 introduces the defect `L[u]` and coupled projection formulas.

The verifier accepts non-unique bounded rational witnesses. It independently checks rank, exact matrix reconstruction, the nonzero symplectic defect, failure of both naive projections, and both corrected identities. It does not evaluate the paper's main theorem, the analytic estimates, or the full corrected proof, and its maximum assurance is `COMPUTED`.
