# Classical matrix groups

Additional classical matrix group families remain deferred. The existing
bounded prime-field `GL(n,q)` and `SL(n,q)` operations have exact matrix
representations and natural actions; they do not imply that every classical
family or quotient has a shared contract.

Symplectic groups require an exact nondegenerate alternating form, orthogonal
groups require quadratic-form semantics (especially in characteristic two),
and unitary groups require a specified field involution. Projective quotients
must preserve their scalar-equivalence and action semantics, and a generator
list needs an exact completeness argument before it represents a named full
group.

No broader family should be added until its own bounded value and operation
contracts are clear. The current demand audit and decision evidence are kept
with the repository's evaluation material in
[`benchmarks/evidence/classical-matrix-groups-admission.md`](../../benchmarks/evidence/classical-matrix-groups-admission.md).
