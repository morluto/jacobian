# Deterministic bottom-up tree-automaton minimization

`tree_automaton.deterministic.minimize.compute` returns the smallest
deterministic quotient over the source ranked signature. It accepts partial or
complete deterministic bottom-up automata. The result retains partiality:
missing transition rows remain undefined.

Only states generated by finite ground trees appear in the quotient. The
`old_to_new` map covers every source state and assigns `-1` to each
unreachable state; `new_to_old` gives the least source-state representative
of each quotient class. If the signature has no nullary transition, no finite
ground tree exists. The result then uses one nonfinal state with no transition
rows, maps every source state to `-1`, and gives its synthetic quotient state
a `null` representative.

For reachable states, refinement begins with final and nonfinal states and
repeatedly separates states whose transitions in any one-hole ground-tree
context differ. Other children of a context range over reachable states, so
the resulting partition is exactly contextual acceptance equivalence. This
is the standard bottom-up tree-automaton semantics described in the
[EPFL tree-automata notes](https://lara.epfl.ch/w/tree_automata).

Reachability scans, refinement contexts, and output rows are admitted before
partition refinement or quotient construction. High-rank signatures can
exceed the refinement budget even when their source transition tables are
small.
