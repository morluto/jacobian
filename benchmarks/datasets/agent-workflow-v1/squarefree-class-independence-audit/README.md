# Squarefree-class independence audit

This Hard benchmark turns a FineProofs olympiad row into a clean-room, multi-stage certificate. It requires the squarefree-kernel equivalence, the exact ordered-pair class count, the transversal interpretation, and a complete modular obstruction to representing 2023 with at most three squares.

The verifier does not trust the dataset proof or require one memorized modulus. It recomputes the submitted quadratic-residue set and exhaustively checks all sums of up to three residues. Assurance is capped at `COMPUTED`; no proof assistant verifies the prose-level squarefree-kernel lemma.
