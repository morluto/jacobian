# Standard parabolic weight orbits

`weyl_group.parabolic_weight.orbit.compute` returns the complete orbit of a
typed `WeightLatticeVector` under the standard parabolic subgroup generated by
the selected simple reflections. The result retains the canonical finite
Cartan datum, the selected generator indices, the source weight, and all
distinct orbit coordinates in the fundamental-weight basis. The empty index
set denotes the trivial subgroup and therefore returns the singleton source
weight.

The operation uses the selected principal Cartan submatrix to determine the
finite subgroup order. It restricts the source weight's simple-coroot
pairings to that subsystem, reflects to its dominant chamber, and computes
the stabilizer order from the zero pairings. Orbit–stabilizer gives the exact
number of output values before the orbit is materialized. A full-Weyl invariant
norm bounds every output coordinate; output size is capped at 4096 vectors.
Requests outside those bounds are rejected without returning a partial orbit.

For `A2` and source weight `(1,0)`, the subgroup generated by `s0` returns
`{(-1,1), (1,0)}`. The subgroup generated by both simple reflections returns
the full three-element orbit `{(-1,1), (0,-1), (1,0)}`.

The finite orbit contract is the elementary action generated by the selected
simple reflections on the parent weight lattice. The implementation does not
depend on an external Weyl-group backend.
