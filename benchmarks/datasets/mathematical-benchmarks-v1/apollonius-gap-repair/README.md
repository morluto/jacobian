# Apollonius gap repair

Hard-provisional Regression benchmark from a human-scored OPC proof. It repairs one exact
coordinate identity that the proof skipped. The verifier accepts arbitrary canonical positive
rational normalizations, independently expands both polynomials, and checks proportionality.

The task targets proof completeness, not answer recovery. Assurance remains `COMPUTED`: only
the annotated algebraic gap is replayed, not every geometric lemma or endpoint convention.
