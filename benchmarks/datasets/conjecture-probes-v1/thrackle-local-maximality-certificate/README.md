# thrackle-local-maximality-certificate

A Regression benchmark from retained row C-051. It requires construction of an exact straight-line thrackle, exhaustive pairwise geometric classification, and a local-maximality certificate against every unused edge.

The verifier uses integer orientation arithmetic and accepts any valid five-edge selection, rather than matching the pentagram by name. The full ten-pair table and five exclusion witnesses prevent answer-only shortcuts. Difficulty is provisionally Hard because construction, exact segment geometry, and maximality all must agree; baseline calibration is pending.
