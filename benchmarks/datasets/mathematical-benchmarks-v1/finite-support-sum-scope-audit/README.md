# Finite-support sum scope audit

Hard-provisional Assurance benchmark from GRAD row 32. The source replaces a
sum over every finite-support binary function by a sum over subsets of
`{1,...,n}`. This loses infinitely many distinct functions whose support lies
beyond `n`, each contributing one.

The task requires an explicit tail-support family proving unbounded partial
sums and a well-posed truncated repair with exact product checkpoints and a
uniform ratio contraction. Quality score: **92/100**.
