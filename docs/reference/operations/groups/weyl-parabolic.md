# Standard parabolic Weyl subgroups

`weyl_group.parabolic.compute` constructs the standard parabolic subgroup
generated by a strictly increasing subset `J` of the parent's simple
reflections. The returned value retains the parent Cartan matrix, the selected
generator indices, the induced principal Cartan submatrix, and the exact
subgroup order. The empty subset denotes the trivial subgroup.

The order is computed from the induced finite Cartan datum's exponents:
`|W_J| = product_{m in exponents}(m + 1)`. The operation returns a subgroup
profile embedded in its parent; it does not enumerate subgroup elements or
minimal coset representatives. Rank is at most 8, and work/output are bounded
before the induced positive-root calculation.
