# BSD infinite-order certificate

An Assurance-family task derived from retained row C-038. Its single objective
is evidence calibration: build a checkable infinite-order rational-point
certificate while refusing to infer analytic rank or Birch–Swinnerton-Dyer.

The verifier accepts alternative bounded curves and points, replays exact group
law arithmetic, and checks every Lutz–Nagell premise. Lutz–Nagell is the sole
trusted mathematical theorem. Difficulty is provisional Hard because the
certificate coordinates curve construction, exact rational multiples,
divisibility, and a subtle open-problem assurance boundary.
