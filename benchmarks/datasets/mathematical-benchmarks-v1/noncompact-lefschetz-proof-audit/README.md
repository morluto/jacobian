# Noncompact Lefschetz proof audit

This task freezes a false compact-support Lefschetz lemma from two public model
answers to First Proof Question 7 and the expert commentary identifying the
counterexample. The source archive is pinned to Codeberg commit
`edde66e7ee4cce5f29f0328f730f0db8e7929d5b`.

The verifier independently replays an arbitrary nonzero rational translation of
the real line, its fixed-point equation, the compact-support cohomology data, and
the resulting Lefschetz number. It checks the logical effect on the submitted
argument but does not answer the original lattice/manifold question or validate
the expert's separate construction.

The archive and review document are public. Their SHA-256 digests and exact file
paths are frozen in `environment/input.json`.
