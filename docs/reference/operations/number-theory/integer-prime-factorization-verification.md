# Integer prime factorization

[Documentation home](../../../index.md) · [Tool surface](../../tools.md)

`integer.compute.prime_factorization` returns the complete prime-power
factorization of one bounded integer. The result uses canonical signed integer
and factor values and is directly reusable by a caller that needs it for a
later calculation.

It is one mathematical operation, not an artifact-producing producer followed
by a generic verification plan.
