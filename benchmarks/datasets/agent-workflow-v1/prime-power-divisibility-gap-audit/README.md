# Prime-power divisibility gap audit

Hard-provisional Assurance benchmark derived from human-scored OPC test row 41. The frozen proof
shows that every prime divisor of a modulus divides a cycle sum, then incorrectly promotes those
primewise facts to divisibility by the full modulus without tracking prime-power multiplicities.

The task requires a freely chosen compressed cycle ledger that satisfies every local prime
divisibility claim while falsifying the promoted global claim. The verifier independently checks
primality, coprimality, all group multiplicities, the exact total, and both p-adic valuations.

Quality score: **89/100**. Difficulty is provisional pending baseline calibration. The task audits
one inference boundary; it does not decide the source olympiad theorem.
