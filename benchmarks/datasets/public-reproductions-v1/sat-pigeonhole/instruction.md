# SAT decision with witness

Decide the exact CNF formula in `input.json`. For a satisfiable formula, return `SATISFIABLE` and a complete Boolean assignment satisfying every clause. For an unsatisfiable formula, return `UNSATISFIABLE`.

## Submission

The verifier replays the task-specific mathematical predicate from the submitted result.

Write `/app/submission.json` to the exact schema in `environment/submission_schema.json`. The submission requires a typed `result`.
