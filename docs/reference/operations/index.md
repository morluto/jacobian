The immutable `operation://catalog` resource is the exact bulk inventory for a
server: it contains every operation ID, request schema, result schema, and
example. For the ordinary agent path, load the matching direct tool through
client search. Use the bulk resource only when an exact catalog-wide snapshot
is genuinely required.
