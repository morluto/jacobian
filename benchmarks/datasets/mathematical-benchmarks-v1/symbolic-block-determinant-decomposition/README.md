# Symbolic block determinant decomposition

Construct a non-unique rational basis that separates the common and sum-zero block-index channels of a symbolic block matrix. The verifier independently replays the similarity transformation over a polynomial ring; it does not trust the source proof or a sampled numerical determinant.

Source: DeepTheorem train row 10002 (source id 86822), pinned by dataset revision and canonical row digest.

The benchmark proves only the frozen symbolic `n=2, k=3` family. It does not claim a machine-checked proof of the unrestricted theorem.
