# normal-projective-chart-audit

An Assurance benchmark from retained row C-016. It tests whether an agent distinguishes an affine eliminant's finite roots from a complete projective parametrization, then repairs the normal-footpoint count with exact algebraic evidence.

The verifier reconstructs all finite and boundary points, checks the ellipse and differential normal equations, and rejects a three-root-only certificate. This is not numerical root finding and not a general theorem claim. Difficulty is provisionally Hard because elimination scope, projective completion, and differential geometry must be coordinated; calibration is pending.
