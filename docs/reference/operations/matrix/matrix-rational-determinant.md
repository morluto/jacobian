# Exact rational matrix determinants

[Documentation home](../../../index.md) · [Tool surface](../../tools.md)

`matrix.determinant.compute` computes the determinant of a bounded square
matrix over ℚ. Its request owns matrix validation; its response returns the
exact canonical rational determinant inline.

For related direct matrix calculations, use the catalog entries for rank, RREF,
inverse, nullspace, characteristic polynomial, and Smith normal form. No
matrix is implicitly retained after a call.
