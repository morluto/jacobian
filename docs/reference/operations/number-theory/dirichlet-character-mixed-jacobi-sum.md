# Exact three-character Jacobi convolution

`dirichlet_character.mixed_jacobi_sum.compute` returns

```text
sum_{a+b+c = 1 (mod N)} chi(a) psi(b) rho(c)
```

for exactly three Dirichlet characters with the same canonical group parent.
Each character is extended by zero off the unit group. The exact output is
represented in the shared rational cyclotomic field generated by the group
exponent and retains all three source characters.

The kernel enumerates two residues and determines the third from the congruence.
It admits the quadratic residue work, field work, and a conservative coefficient
growth bound before constructing the cyclotomic polynomial or summing terms.
This operation does not offer an arbitrary multi-character arity or a symbolic
finite-sum language.
