# Euler fourth-power scope audit

Hard counterexample-and-scope benchmark derived from a MathOverflow discussion of
experimental mathematics. The verifier accepts any primitive, positive, bounded
three-summand fourth-power identity, recomputes the exact equality and every required
modular checksum, and rejects claims extending beyond the frozen proposition.

Selected because it adds exact large-integer witness validation and assurance-scope
calibration without duplicating finite residue obstruction, graph realization, or
polynomial counterexample tasks. Nearby famous conjecture examples were rejected when
their first known counterexamples were too large for a practical clean-room verifier.
