# Stanley-Reisner ideals

`topology.simplicial_complex.stanley_reisner_ideal.compute` constructs the
squarefree monomial ideal generated by the complete minimal-nonface antichain
of a finite simplicial complex. Each generator has coefficient one and one
exponent for every variable in the returned ordered polynomial axis.

The result retains the exact source complex, a `RationalPolynomialIdeal`, and
an ordered binding from each source vertex label to a collision-free variable
name (`v0`, `v1`, ...). Vertex labels are never parsed or rewritten as
polynomial identifiers. The ideal composes directly with the monomial-ideal
Betti operation; the binding retains the vertex interpretation of its axes.

The polynomial carrier admits at most eight vertices and 64 generators for
this operation. It represents the zero ideal using its existing singleton
zero-polynomial generator, so a simplex is handled without introducing a
second ideal type. The minimal-nonface search and result size are bounded. A
deserialized result consumer that relies on the source-to-variable relation
must authenticate that relation.
