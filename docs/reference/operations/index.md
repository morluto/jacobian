# Operation references

[Documentation home](../../index.md) · [Tool surface](../tools.md)

The immutable `operation://catalog` resource is the exact bulk inventory for a
server: it contains every operation ID, request schema, result schema, and
example. For the ordinary agent path, use the matching and inspection modes of
`math.find` to identify candidates and read one exact operation contract.
